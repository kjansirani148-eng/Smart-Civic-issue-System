# Smart Civic Issue Reporting Platform

A Flask-based civic issue reporting web application for citizens, officers, and administrators.

## Features

- Citizen registration and login
- Complaint reporting with photo uploads
- Automatic location capture
- Complaint status tracking
- Officer work assignment and status updates
- Admin management of users, officers, complaints, and categories
- AWS S3 image storage support
- MySQL database with SQLAlchemy ORM
- Role-based access control and CSRF protection

## Technology Stack

- Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
- Backend: Python Flask
- Database: MySQL
- Cloud Storage: AWS S3
- Deployment: AWS EC2 Ubuntu 24.04
- Authentication: Flask-Login
- ORM: SQLAlchemy

## Setup

1. Clone the repository.
2. Create and activate a virtual environment:
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```
3. Install dependencies:
   ```powershell
   pip install -r requirements.txt
   ```
4. Copy `.env.example` to `.env` and update values.
5. Create the MySQL database and run schema:
   ```powershell
   mysql -u root -p < schema.sql
   mysql -u root -p smart_civic < sample_data.sql
   ```
6. Start the app:
   ```powershell
   python run.py
   ```

## Default Credentials

- Admin: `admin@smartcivic.local` / `password`
- Sample citizen: `jane.user@example.com` / `password`

## Project Structure

- `app/` - Flask application package
- `templates/` - Jinja2 templates for pages
- `static/` - CSS and JavaScript assets
- `schema.sql` - Database schema script
- `sample_data.sql` - Seed data including categories and statuses
- `requirements.txt` - Python dependencies
- `run.py` - Application entrypoint
